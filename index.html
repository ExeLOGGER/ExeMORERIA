Webhook URL Channel / Server ID
That looks like a channel or server ID, not a webhook.
Channel and server IDs cannot send messages directly — you need a webhook URL created inside that channel.
How to get the webhook URL:
1Open your Discord server, go to the target channel
2Click the gear icon (Edit Channel) next to the channel name
3Go to Integrations tab → click Webhooks
4Click New Webhook → give it a name → click Copy Webhook URL
5Paste that full URL here
